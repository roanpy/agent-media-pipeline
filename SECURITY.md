# Security Policy

## Supported versions

Only the latest release is supported with security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for an unpatched vulnerability, and do not include API keys, cookies, signed URLs, private media, or private filesystem paths in a report.

Include the affected version, operating system, minimal reproduction steps, impact, and any suggested mitigation. You should receive an initial response within seven days.
